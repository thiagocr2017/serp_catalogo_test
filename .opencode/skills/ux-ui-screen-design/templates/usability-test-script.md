# 🧪 Script Test Usabilidad

> **Guía para test de usabilidad moderado. 5 usuarios = 80% problemas encontrados.**

---

## 📋 Preparación Pre-Test

### Reclutamiento (5-8 usuarios)
| Criterio | Detalle |
|----------|---------|
| Perfil | Representativo usuarios reales |
| Número | 5-8 usuarios |
| Incentivo | $50-100 / 45-60 min |
| Grabación | Pantalla + audio (consentimiento) |

### Materiales
- [ ] Prototipo funcional (Figma/Storybook/Staging)
- [ ] Guion impreso
- [ ] Consentimiento firmado
- [ ] Grabación pantalla + audio
- [ ] Cuestionario post-test (SUS)
- [ ] Incentivo preparado

---

## 📝 Guion de Test (45-60 min)

### 1. Bienvenida (5 min)
> "Gracias por participar. No hay respuestas correctas/incorrectas. Probamos el producto, no a ti. Piensa en voz alta."

**Preguntas Ice-breaker:**
- "¿Cuál es tu rol?"
- "¿Con qué frecuencia usas [producto類似]?"

### 2. Tareas Core (30-40 min)

#### Tarea 1: [Objetivo Principal]
> "Imagina que quieres [objetivo]. Muéstrame cómo lo harías."

**Métricas:**
- [ ] Completado: Sí/No
- [ ] Tiempo: ___ seg
- [ ] Errores: ___
- [ ] Path: _______________
- [ ] Comentarios: _______________

#### Tarea 2: [Objetivo Secundario]
> "Ahora quieres [objetivo 2]. ¿Cómo lo harías?"

**Métricas:**
- [ ] Completado: Sí/No
- [ ] Tiempo: ___ seg
- [ ] Errores: ___
- [ ] Path: _______________

#### Tarea 3: [Edge Case / Error Recovery]
> "Algo sale mal. [Escenario]. ¿Qué haces?"

### 3. Preguntas Post-Tareas (10 min)

**SUS (System Usability Scale) - 10 preguntas, escala 1-5:**
1. Creo que usaría este sistema frecuentemente
2. Lo encuentro innecesariamente complejo
3. Es fácil de usar
4. Necesitaría ayuda técnica
5. Funciones bien integradas
6. Demasiada inconsistencia
6. La mayoría aprendería rápido
7. Me parece muy incómodo
8. Me siento seguro usándolo
8. Necesito aprender mucho antes

**Preguntas Abiertas:**
- "¿Qué te gustó más?"
- "¿Qué te frustró más?"
- "¿Qué cambiarías?"
- "¿Recomendarías a un colega? (0-10)"

### 4. Cierre (5 min)
- Agradecer
- Entregar incentivo
- Contacto para dudas
