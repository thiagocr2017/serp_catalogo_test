# 📐 Principios UX Fundamentales (Inquebrantables)

> **Estos 10 principios son ley. No son sugerencias.**

---

## 1. **Usuario Primero, Siempre**
> "No eres el usuario. No diseñes para ti."
- Investiga antes de diseñar
- Valida con usuarios reales
- Métricas de éxito = métricas de usuario

## 2. **Simplicidad Radical**
- Una pantalla = un objetivo principal
- Elimina todo lo que no sirve al objetivo
- "La perfección se alcanza no cuando no hay nada más que añadir, sino cuando no hay nada más que quitar"

## 3. **Consistencia = Confianza**
- Mismos patrones = mismo comportamiento
- Design system = lenguaje compartido
- Romper consistencia = romper confianza

## 4. **Feedback Inmediato y Honesto**
- < 100ms respuesta visual
- Estados claros: idle → loading → success/error
- Nunca "¿pasó algo?"

## 5. **Accesibilidad = Derecho, No Feature**
- WCAG 2.1 AA mínimo
- Si no es accesible, está roto
- No solo color para info crítica

## 6. **Prevención > Corrección**
- Validación inline (no al enviar)
- Undo > Confirmación modal
- Undo > Confirmación destructiva

## 7. **Carga Cognitiva Mínima**
- 7±2 items en memoria de trabajo
- Agrupa por proximidad (Gestalt)
- Scan-friendly: headings, bullets, whitespace

## 7. **Feedback > Silencio**
- Cada acción = respuesta visible
- < 100ms = instantáneo
- Loading states obligatorios > 300ms

## 9. **Errores = Oportunidad de Ayuda**
- Mensajes humanos, no técnicos
- Qué pasó + qué hacer
- Inline > Toast > Modal

## 10. **Consistencia > Innovación Visual**
- Innovar en resolución de problema, no en patrones
- Design system = contrato
- Romper patrón = justificación documentada

---

## 🎯 Aplicación Práctica

**Antes de cada decisión de diseño:**
1. ¿Qué problema del usuario resuelve?
2. ¿Reduce fricción o la añade?
3. ¿Es accesible?
4. ¿Es consistente con el sistema?
4. ¿Se puede deshacer?

**Si dudas → elige la opción que reduzca fricción al usuario.**
