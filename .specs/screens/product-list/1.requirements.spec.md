# Product List - Requirements

## Proposito

Mostrar productos con busqueda, filtros y acciones de navegacion hacia crear,
editar y consultar ficha tecnica.

## Alcance actual

- Listar productos.
- Buscar o filtrar segun alcance implementado.
- Abrir formulario de creacion.
- Abrir formulario de edicion o ficha del producto.

## Escenarios

### Consultar lista

Given existen productos activos  
When el usuario abre la pantalla  
Then ve la lista con informacion suficiente para identificar cada producto.

### Abrir edicion

Given el usuario selecciona un producto  
When ejecuta la accion de editar  
Then navega al formulario con los datos del producto cargados.

## Fuera de alcance

- Importacion/exportacion masiva.
- Generacion de catalogo PDF.
- Reglas de precios promocionales detalladas.
