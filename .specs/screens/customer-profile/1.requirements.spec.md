# Customer Profile - Requirements

## Proposito

Crear una pantalla de perfil/display del cliente que concentre informacion
comercial, fiscal, historica, financiera y operativa para mejorar la relacion
con el cliente sin convertir el formulario de edicion en un tablero saturado.

## Alcance objetivo

- Mostrar datos generales: nombre fiscal, nombre fantasia, estado, telefonos,
  correos, direccion y geografia.
- Mostrar contactos con rol, telefono, email si existe y cumpleanos.
- Mostrar preferencias: factura electronica/tiquete, tipo de cliente,
  condiciones de credito, categoria manual, categoria inteligente y envio.
- Mostrar resumen comercial: ultima compra, productos frecuentes, productos
  comprados recientemente, pedidos abiertos, cotizaciones activas, facturas,
  devoluciones y consignaciones.
- Mostrar resumen financiero: saldo, cuenta por cobrar, limite disponible,
  documentos vencidos y alertas basicas.
- Mostrar alertas: cliente inactivo, credito vencido, saldo sobre limite,
  documentos pendientes, datos fiscales incompletos, email faltante para factura
  electronica.
- Permitir navegar a documentos relacionados sin importar internals de otros
  modulos.

## Principios UX

- El primer vistazo debe responder: quien es, si puedo venderle, que le debo
  cuidar y como contactarlo.
- Usar tarjetas compactas de resumen, no una lista interminable de campos.
- Separar informacion editable de informacion calculada.
- Las alertas deben ser accionables y breves.
- Los historiales largos deben tener filtros y enlaces a pantallas de detalle.

## Layout propuesto

- Encabezado: nombre fantasia, nombre fiscal, estado, categoria, acciones.
- Banda de alertas: credito, documentos, datos incompletos.
- Columna izquierda: datos de contacto, fiscal, envio y condiciones.
- Area central: resumen comercial y financiero.
- Seccion inferior o tabs: documentos, productos, contactos, actividad.

## Escenarios

### Cliente con saldo vencido

Given el cliente tiene facturas vencidas o saldo pendiente  
When se abre el perfil  
Then se muestra alerta visible con monto y acceso al detalle.

### Cliente contado

Given el cliente es contado  
When se abre el perfil  
Then se indica que no puede facturar a credito.

### Productos frecuentes

Given existen compras historicas  
When se abre el perfil  
Then se muestran productos frecuentes y fecha de ultima compra.

### Datos fiscales incompletos

Given el cliente requiere factura electronica y faltan datos fiscales/email  
When se abre el perfil  
Then se muestra alerta antes de crear documentos fiscales.

## Fuera de alcance inicial

- Motor completo de CRM.
- Envio automatico de emails.
- Calculo definitivo de ranking inteligente si no se define la formula.
- Pantalla final de logistica/envios.
