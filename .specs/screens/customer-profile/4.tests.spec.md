# Customer Profile - Tests

## Cobertura obligatoria

- Renderiza datos generales del cliente.
- Muestra nombre fantasia y nombre fiscal cuando ambos existen.
- Muestra contactos y telefonos formateados.
- Muestra los datos fiscales: tipo de identificacion resuelto desde el catalogo,
  actividad economica y si requiere factura electronica.
- ~~Muestra alerta de datos fiscales incompletos cuando aplica.~~ **Diferido**
  por la decision 34 (`../modules/sales/customer-management/0.open-questions.md`),
  que deja fuera de la primera version las alertas de datos fiscales
  incompletos y email fiscal faltante. Este archivo exigia esa alerta; manda la
  decision. Si se revierte la decision, reactivar la cobertura.
- Muestra alerta de cliente inactivo.
- Muestra resumen vacio cuando no hay compras.
- Muestra ultima compra y productos frecuentes cuando existen.
- Muestra documentos relacionados sin romper si no hay pagos o devoluciones.
- Pedidos, facturas, devoluciones, cotizaciones y consignaciones filtran por
  customerId; registros legacy por nombre exacto no se duplican.
- El acceso contextual a devolucion informa que no esta disponible y permite
  volver al perfil conservando `invoiceId`, sin mutacion.
- Detalle de factura enlaza al cliente y devuelve al perfil/lista de origen.
- Perfil abierto desde detalle de factura muestra tooltip `Volver al documento`
  y conserva el retorno al mismo detalle.
- Alerta de pendientes abre detalle real con conteos por categoria/estado;
  loading/error no se presentan como lista vacia.
- Navega desde lista de clientes al perfil.
- Desde el perfil, la flecha accesible como `Volver a clientes` navega a
  `/sales/customers` y `Editar` permanece en la zona de acciones.
- Desde una ruta de detalle de cliente, seleccionar `Clientes` en el menu
  lateral navega a `/sales/customers` y no deja al usuario en el perfil actual.
- Muestra banda de decision con estado, credito, contacto y proxima accion.
- Ordena alertas con severidad financiera antes que documentos pendientes.
- Cada pestana de documentos vacia muestra copy especifico.
- Limita chips visibles en encabezado y conserva categorias/rankings en una
  seccion secundaria.
- Expone semantica accesible para editar y abrir el perfil desde la lista.
- Lista cotizaciones borrador y no borrador del cliente con estado inequívoco.
- Cada cotizacion abre su documento y vuelve al mismo perfil.
- Desde el perfil se marcan estados permitidos y se invalidan documentos tras
  mutacion exitosa; errores conservan estado visible anterior.

## Criterio de listo

La pantalla no se considera lista si solo muestra datos estaticos del cliente.
Debe incluir al menos alertas basicas, resumen comercial y navegacion a editar.
