# Presentaciones en Configuracion - Plan Tecnico

- UI en `lib/modules/configuration/presentation/pages/settings_page.dart`.
- DTO y comandos publicos incluyen `unitsPerPresentation`.
- RPC `SECURITY DEFINER` escribe nombre/factor de forma transaccional y con
  idempotencia/versionado existentes.
- `ProductApi` consume la presentacion publica y guarda el factor derivado.
- Cotizaciones conservan el snapshot `presentationName` y
  `unitsPerPresentation`.
- Sin imports internos entre modulos; pruebas Flutter y pgTAP independientes.
