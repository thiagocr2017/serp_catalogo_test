# Presentaciones en Configuracion - Requisitos

- Cada presentacion tiene nombre y cantidad entera positiva de unidades.
- Crear y editar validan ambos campos antes de persistir.
- La lista muestra nombre y factor, por ejemplo `Caja · 6 unidades`.
- El catalogo seleccionado por Producto es la fuente del incremento de venta.
- Cambiar el factor actualiza el valor operativo de productos asociados para
  ventas futuras; cotizaciones existentes conservan su snapshot.
- Desactivar una presentacion conserva documentos y productos historicos.
