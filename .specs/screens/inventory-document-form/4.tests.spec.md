# Inventory Document Form - Tests

## Estado actual

Pendiente. `.specs/testing/form-coverage.md` registra este formulario como no listo.

## Cobertura obligatoria

- Rechazar documento sin lineas.
- Rechazar linea sin producto.
- Rechazar cantidad invalida.
- Confirmar documento valido.
- Verificar creacion atomica de documento y movimientos.
- Verificar que un error de persistencia no deja movimientos huerfanos.
- Verificar auditoria cuando aplique.
- Verificar que salir con cambios pide confirmacion y que cancelar la
  confirmacion mantiene el formulario abierto.
- Verificar que guardar correctamente abre el detalle, cuyo retorno lleva al
  indice `/inventory/documents`.

## Criterio de listo

El formulario no se considera listo hasta tener prueba de UI o integracion que
demuestre confirmacion real, validaciones negativas y atomicidad.
