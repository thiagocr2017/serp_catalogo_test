# Inventory Document Form - Technical Plan

## Archivos principales

- `lib/modules/inventory/presentation/pages/inventory_document_form_page.dart`
- `lib/modules/inventory/domain/entities/inventory_document.dart`
- `lib/modules/inventory/api/inventory_api.dart`
- `test/modules/inventory/presentation/`

## Dependencias permitidas

El formulario pertenece a `inventory`. Para seleccionar productos debe consumir
contratos publicos del modulo `product`; no debe importar capas internas.

## Navegacion

- El `leading` del `AppBar` ofrece flecha icon-only con tooltip `Volver` hacia
  `/inventory`.
- La accion consulta `UnsavedChangesGuard` y conserva el formulario si se
  cancela el descarte.
- Guardar abre `/inventory/documents/:id`; el detalle tiene retorno visible a
  `/inventory/documents`.

## Riesgos

- Confirmar parcialmente un documento.
- Crear movimientos sin documento asociado.
- Permitir cantidades invalidas.
- Saltarse auditoria.
