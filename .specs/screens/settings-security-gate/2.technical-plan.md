# Puerta de seguridad de Configuracion - Plan Tecnico

- UI de entorno en `settings_page.dart`: mostrar aviso bloqueado, sin boton ni
  dialogo de confirmacion durante la migracion.
- `SupabaseConfigurationRepository.get` deja de reclamar superadministrador y
  de confiar en el identificador de dispositivo para `isSuperAdmin`.
- El metodo de purga del repositorio falla localmente hasta habilitacion
  explicita posterior al bootstrap Auth.
- Migracion aditiva revoca `EXECUTE` heredado en bootstrap por dispositivo y
  purga/transicion para `PUBLIC`, `anon` y `authenticated`.
- pgTAP valida privilegios efectivos; prueba de widget verifica el bloqueo.
- No se modifica el resto de grants comerciales en este paso.
