# Customer List - Requirements

## Proposito

La lista de clientes debe funcionar como pantalla de busqueda, seleccion y
lectura rapida del estado comercial del cliente. No debe intentar reemplazar el
perfil completo del cliente.

## Escenarios

### Busqueda inteligente

Given que existen clientes registrados,
When el usuario escribe uno o varios terminos en la busqueda,
Then la lista debe mostrar clientes que coincidan con nombre legal, nombre
fantasia, telefono, correo, identificacion, provincia o gira.

- La busqueda comienza al escribir el tercer caracter. Con menos de tres
  caracteres, el filtro queda limpio; borrar hasta ese punto restaura los
  resultados y conserva los filtros de estado/tipo.

### Filtros operativos

Given que existen clientes activos, inactivos, contado y credito,
When el usuario aplica filtros de estado o tipo,
Then la lista debe reducirse sin perder el texto de busqueda actual.

Given que la busqueda o los filtros reducen la lista,
When la pantalla muestra resultados,
Then debe indicar cuantos clientes se muestran del total disponible.

Given que la busqueda o los filtros no encuentran coincidencias,
When el usuario ve el estado sin resultados,
Then debe explicar que puede ajustar los filtros y ofrecer una accion
`Limpiar filtros` que restaure busqueda, estado y tipo a sus valores por
defecto.

### Lectura rapida

Given que el usuario revisa la lista,
When ve una fila de cliente,
Then debe poder reconocer nombre fantasia/legal, tipo de cliente, dias de
credito cuando aplique, ubicacion/gira, telefono o correo, y estado activo.

### Estado vacio

Given que no existe ningun cliente registrado,
When el usuario entra a la lista,
Then debe ver un estado vacio accionable con el mensaje de ausencia y la accion
`Crear primer cliente`.

La lista ofrece `Importar clientes` en ambos estados (con y sin resultados) y
abre la pantalla secundaria `/sales/customers/import`.

### Accesibilidad

Given que el usuario navega con teclado o tecnologias asistivas,
When enfoca busqueda, filtros, crear cliente, limpiar filtros o una fila/card,
Then cada control debe exponer nombre accesible y proposito claro.

## Fuera de alcance actual

- Perfil completo de cliente con compras, devoluciones, pedidos y saldos.
- Ranking de clientes por compras, frecuencia o LTV.
- Edicion full-page de cliente.
- Acciones masivas.
