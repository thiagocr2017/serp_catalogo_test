# Customer List - Tests

## Casos minimos

- Buscar por nombre legal muestra el cliente esperado.
- Buscar por nombre fantasia muestra el cliente esperado.
- Buscar por telefono muestra el cliente esperado.
- Filtro `Activos` oculta clientes inactivos.
- Filtro `Credito` muestra solo clientes de credito.
- Busqueda sin coincidencias muestra estado vacio.
- Busqueda o filtros activos muestran conteo de resultados contra el total.
- `Limpiar filtros` restaura texto de busqueda, estado y tipo.
- Lista sin clientes muestra `Crear primer cliente`.
- Las cards/filas de cliente tienen nombre accesible y navegan al perfil.
