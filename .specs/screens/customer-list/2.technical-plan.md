# Customer List - Technical Plan

## Archivos

- `lib/modules/sales/presentation/pages/customers_page.dart`

## Implementacion

- Mantener la pantalla dentro del modulo `sales`.
- Usar `customersProvider` como fuente actual.
- Filtrar localmente mientras no exista busqueda server-side.
- Normalizar la busqueda con terminos separados por espacios.
- Mostrar informacion densa y escaneable en filas/cards simples.

## Compatibilidad

No cambia contratos de base de datos ni APIs. La busqueda es visual/local y
puede reemplazarse por consulta paginada cuando el volumen de clientes lo
requiera.

## Decision UX

La lista es una pantalla operativa. Debe ayudar a encontrar y abrir clientes,
no concentrar todo el historial comercial. El historial y alertas pertenecen al
perfil/display de cliente.
