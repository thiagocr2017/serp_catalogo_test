# Product Profile - Test Spec

- Render the profile at 320 logical pixels with long SKU and barcode values.
- Assert no Flutter layout exception is reported.
- Assert the copy action remains present with its tooltip; clipboard receives
  the complete original value when activated.
- Buyer and history searches show all contextual rows below three characters,
  filter from the third, and restore all rows when shortened or cleared.
- Editing from the profile and saving returns to that product's profile.
