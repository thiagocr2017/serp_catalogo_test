# Importacion masiva de clientes - Pruebas

## Servicio

- Plantilla incluye encabezados canonicos del alcance.
- Parseo admite coma/punto y coma, BOM UTF-8, tildes y columnas reordenadas.
- Validacion detecta encabezados/campos requeridos, telefono/email, valores
  monetarios, dias de credito, categorias inexistentes y duplicados.
- Credito valido conserva dias/limite; contado deja dias nulos.
- Errores de parseo y filas vacias no llaman a la API.
- Altas validas usan `TICKET` y no requieren factura electronica.
- Fallo individual de API se reporta sin perder resultados previos.

## Pantalla y navegacion

- Lista expone accion `Importar clientes` con o sin datos.
- La pantalla secundaria tiene retorno visible a la lista.
- No importa sin archivo, filas validas y cero errores de validacion.
- Vista previa muestra conteos y errores por fila.
- Resultado total/parcial informa creados y fallos; invalida `customersProvider`.
- Error de lectura permite seleccionar otro archivo.

La suite widget de seleccion/retorno queda pendiente: `file_selector` usa un
dialogo nativo y requiere un adapter inyectable antes de afirmar el ciclo de
seleccion de archivo sin automatizacion fragil del sistema operativo.
