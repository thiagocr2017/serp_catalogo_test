# Catálogo PDF - Plan técnico

- Mantener `catalogOrder` y `categoryOrder` como estado de edición local.
- Mantener snapshots `_savedCatalogOrder` y `_savedCategoryOrder` como baseline
  para descartar y detectar cambios pendientes.
- Los callbacks de mover solo mutan estado local y recalculan `_orderDirty`.
- La barra de guardar/descartar se presenta fija en el Scaffold mientras haya
  cambios pendientes.
- Un único guardado construye las listas completas, invoca
  `ProductRepository.saveCatalogOrder`, invalida los datos del catálogo y
  vuelve a cargar el preview conservando el orden guardado como baseline.
- La acción independiente `Actualizar catálogo` invalida categorías y lista,
  vuelve a leer el orden persistido y reinicia el baseline; queda deshabilitada
  mientras existan cambios locales pendientes.
- El `loadingWidget` del preview muestra progreso mientras se genera/rasteriza;
  la transición a 100% se dispara cuando PdfPreview termina de cargar sus
  páginas, no al terminar la consulta ni solo al crear los bytes PDF.
- Cada actualización incrementa una generación usada como key de `PdfPreview`,
  invalidando su caché interna y forzando reconstrucción de las páginas. El
  callback del estado de carga debe pertenecer a esa misma generación.
- El indicador de carga usa fondo opaco y texto `onSurface` para conservar
  contraste en tema claro y oscuro.
- Cada lista desplazable con `Scrollbar` en las pestañas tiene un
  `ScrollController` propio compartido solo por esa barra y su `ListView`; no
  depende del `PrimaryScrollController` al cambiar de pestaña o salir.
- El armado de listas usa mapas por ID, no búsquedas anidadas sobre todos los
  productos.
- Los bytes de imagen del preview PDF se reutilizan mediante una caché LRU en
  memoria, limitada a 128 URL, y se deduplican descargas concurrentes. Al
  reemplazar imágenes se genera una URL versionada para evitar servir bytes
  viejos.
- Las imágenes se optimizan en memoria para la resolucion impresa segun
  tarjetas por pagina, sin cambiar los archivos de origen del almacenamiento;
  transparencia se conserva y las imagenes JPEG pequeñas no se recomprimen.
