# Catálogo PDF - Requisitos

## Propósito

Configurar y previsualizar un catálogo PDF comercial con selección y orden de
categorías y productos.

- Las busquedas de seleccion y orden filtran desde el tercer caracter; borrar
  hasta dos caracteres restaura la lista completa sin alterar selecciones ni
  orden local.

## Orden de categorías y productos

- Subir y Bajar modifican solo el orden local en memoria; no realizan lecturas
  ni escrituras remotas por cada movimiento.
- La vista previa refleja inmediatamente el orden local actual.
- Mientras el orden difiera del último orden guardado, se muestran las acciones
  `Guardar` y `Descartar` en una barra fija visible aunque el usuario cambie de
  pestaña.
- `Guardar` persiste categorías y productos en una sola llamada de orden,
  actualiza los datos del preview y deja el nuevo orden como línea base.
- Si guardar falla, se conserva el orden local y las acciones siguen visibles
  para permitir reintentar o descartar.
- `Descartar` restaura exactamente el último orden guardado sin llamar al
  repositorio.
- `Actualizar catálogo` vuelve a consultar productos y categorías y reconstruye
  el preview desde el orden persistido, sin guardar cambios locales.
- Durante la generación y rasterización del preview se muestra una barra de
  progreso con `Renderizando catálogo...`; al estar las páginas listas muestra
  `Catálogo listo · 100%` y no muestra un snackbar de éxito prematuro.
- El estado de render usa una superficie opaca y texto de alto contraste.
- El PDF reduce imagenes grandes segun el tamaño que ocupa cada tarjeta,
  preserva transparencia y no modifica los archivos guardados del producto.
- `Actualizar catálogo` fuerza una nueva instancia del preview para que se
  regeneren y rastericen las páginas sin salir de la pantalla.
- `Actualizar catálogo` se deshabilita mientras haya cambios de orden sin
  guardar, para evitar descartar accidentalmente el borrador.
- Si el usuario vuelve manualmente al último orden guardado, el estado pendiente
  se limpia y la barra deja de mostrarse.
- Guardar está deshabilitado durante la persistencia para evitar solicitudes
  duplicadas.
