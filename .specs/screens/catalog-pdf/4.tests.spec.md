# Catálogo PDF - Pruebas

- Las cuatro busquedas de seleccion/orden no filtran con uno o dos caracteres,
  filtran desde el tercero y restauran resultados al borrar debajo del umbral.
- Filtrar y limpiar no cambia los ids seleccionados ni el orden local.

- Reordenar categoría cambia inmediatamente el orden del preview y no llama al
  repositorio hasta pulsar Guardar.
- Reordenar producto cambia inmediatamente el preview y no llama al
  repositorio hasta pulsar Guardar.
- Guardar realiza una sola llamada con listas completas, oculta el estado
  pendiente y refresca el preview con el orden persistido después de una
  respuesta exitosa.
- Descartar restaura ambas listas al baseline y no llama al repositorio.
- Si guardar falla, el orden editado permanece visible y se puede reintentar o
  descartar.
- La barra de acciones pendientes sigue visible al cambiar de pestaña.
- Volver al orden baseline limpia el estado pendiente.
- Actualizar catálogo consulta de nuevo productos y categorías y refleja el
  orden persistido sin ejecutar `saveCatalogOrder`.
- Actualizar catálogo queda deshabilitado si hay cambios locales pendientes.
- Durante la rasterización se ve el progreso y solo al cargar las páginas se
  muestra `Catálogo listo · 100%`; no aparece antes un snackbar de éxito.
- Actualizar incrementa la generación del preview y dispara de nuevo la
  generación/rasterización en la pantalla actual.
- Regenerar el preview con la misma URL de imagen reutiliza bytes cacheados; una
  URL versionada distinta provoca una descarga nueva.
- Imagenes mayores al limite de impresion se reducen para PDF, mantienen su
  transparencia y producen menos bytes; JPEG pequeños se reutilizan sin
  recomprimir.
- El texto de carga mantiene contraste visible en tema claro y oscuro.
- Navegar entre pestañas y salir de Catálogo con las listas desplazables
  visibles no produce errores de `Scrollbar` sin `ScrollPosition`.
