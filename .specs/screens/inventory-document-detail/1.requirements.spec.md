# Inventory Document Detail - Requirements

## Proposito

Consultar un documento de inventario y regresar con claridad al indice de
documentos.

## Alcance

- Mostrar numero, tipo, estado, bodegas/ubicaciones, notas y lineas.
- Permitir abrir el perfil de cada producto relacionado.
- Mostrar la accion `Volver a documentos` que navega a
  `/inventory/documents`, incluso durante carga o cuando el documento no exista.
- El detalle es de consulta; no existe ruta de edicion para
  `/inventory/documents/:id/edit`.

## Escenarios

### Volver al indice

Given el usuario esta viendo un documento de inventario
When selecciona `Volver a documentos`
Then se abre `/inventory/documents`.

### Documento inexistente

Given el ID no corresponde a un documento
When se muestra el estado no encontrado
Then el usuario conserva la accion `Volver a documentos`.

## Cambios sin guardar

El detalle no es editable y no mantiene cambios locales. El formulario de
creacion confirma el descarte al salir cuando esta sucio; despues de guardar
abre el detalle del documento.
