# Inventory Document Detail - Test Spec

## Cobertura

- Muestra datos del documento cargado.
- La flecha con tooltip `Volver a documentos` navega a `/inventory/documents`.
- La salida sigue disponible cuando el documento no existe.
- La ruta de lectura no ofrece accion de edicion.

## Criterio de listo

La prueba de widget verifica la navegacion desde el detalle a la lista dentro
del shell de escritorio.
