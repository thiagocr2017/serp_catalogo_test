# Product Form - Requirements

## Proposito

Permitir crear y editar productos con datos comerciales, abastecimiento,
categoria, precio, stock inicial y estado activo, manteniendo integridad con
inventario cuando aplique.

## Alcance actual

- Crear producto valido con stock inicial.
- Cargar producto existente para edicion.
- Actualizar producto existente.
- Validar requeridos y campos numericos antes de guardar.
- Mantener el formulario abierto cuando hay errores de validacion o persistencia.

## Escenarios

### Crear producto valido

Given el usuario completa los campos obligatorios con valores validos  
When guarda el formulario  
Then se crea el producto y, si hay stock inicial, se registra el movimiento de
inventario correspondiente.

### Bloquear datos invalidos

Given el usuario deja requeridos vacios o ingresa numeros invalidos  
When intenta guardar  
Then el formulario muestra errores, permanece abierto y no ejecuta el comando de
guardado.

### Editar producto existente

Given existe un producto cargado  
When el usuario modifica campos editables y guarda  
Then se persisten los cambios sin recrear el producto ni duplicar stock inicial.

### Salir del formulario

Given el formulario de producto esta abierto desde la lista o el perfil
When el usuario usa la accion volver del encabezado
Then vuelve al contexto que lo abrio; si hay cambios sin guardar, puede seguir
editando o confirmar el descarte.

## Fuera de alcance

- Importacion/exportacion masiva.
- Generacion de catalogo PDF.
- Eliminacion o desactivacion desde este formulario.
