# 4. Pruebas y Contrato de Aceptación

## Pruebas Unitarias y de Widget
- **Formulario:** Verificar que intentar enviar el formulario vacío muestra errores de validación y bloquea el envío.
- **Validación de Email:** Verificar que un email malformado es rechazado.

## Pruebas End-to-End (E2E)
- **Flujo de Acceso Denegado:** Entrar a la app sin sesión redirige a `/login`.
- **Login Fallido:** Ingresar credenciales incorrectas muestra un error visible al usuario, no cambia de pantalla.
- **Login Exitoso:** Ingresar credenciales correctas redirige a `/products`.
- **Cierre de Sesión:** (si está implementado en esta fase) Verificar que cerrar sesión redirige a `/login`.

## Pruebas de Base de Datos (pgTAP)
- (En otro archivo, pero relacionado) El inicio de sesión con Supabase genera una sesión Auth que el backend acepta.
