# 3. Tareas

1. **Configuración de Módulo:** Crear la estructura `lib/modules/authorization/` con sus subcarpetas.
2. **Capa de Datos:** Implementar `AuthRepository` para abstraer Supabase Auth (`signIn`, `signOut`, `authStateChanges`).
3. **Capa de Presentación (Controladores):** Implementar `authProvider` (estado de la sesión actual) y `LoginController` (estado del formulario y acción de submit).
4. **Capa de Presentación (UI):** Crear `LoginPage` usando componentes compartidos (`SerpTextField`, botones), validando inputs.
5. **Enrutamiento:** Agregar `/login` a `app_router.dart` e implementar el guard de rutas (`redirect`) basado en `authProvider`.
6. **Desactivar Sign Up:** Editar `supabase/config.toml` para apagar el registro y sign-in anónimo (después de ajustar los E2E tests).
7. **Refactor E2E Tests:** Cambiar los tests E2E existentes (y el nuevo flujo de login) para usar un usuario de prueba en Supabase local pre-creado (fixture) o creado directamente en SQL para el test.
