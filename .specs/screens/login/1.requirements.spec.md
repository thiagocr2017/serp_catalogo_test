# 1. Requisitos de la Pantalla de Login

## Objetivo
Proveer un punto de entrada seguro donde los usuarios pre-aprovisionados puedan autenticarse mediante correo y contraseña utilizando Supabase Auth, reemplazando el acceso anónimo previo.

## Usuarios
- Usuarios y superadministradores aprovisionados fuera del cliente (no hay auto-registro).

## User Journey
- Happy Path: Ingresa credenciales -> Clic en "Iniciar Sesión" -> Autenticado -> Redirección a `/products` (o ruta solicitada).
- Credenciales inválidas: Ingresa credenciales -> Clic en "Iniciar Sesión" -> Error de credenciales -> Muestra mensaje en UI.

## Restricciones
- No debe haber botón de "Registrarse" o "Crear cuenta".
- La recuperación de contraseña, por ahora, no está expuesta en UI de cliente a menos que se defina.
- El diseño debe adherir a la Gobernanza Visual ("macOS Precision Enterprise"): Tema oscuro por defecto, botones squircle (8px), tarjeta (12px), sin colores hardcodeados.

## Estados
- **Vacío:** Formulario listo para ingresar email y password.
- **Cargando:** Botón de inicio bloqueado, indicador de progreso.
- **Error:** Mensaje (Toast o banner) indicando error (credenciales incorrectas, offline).
- **Éxito:** Redirección automática, no requiere pantalla intermedia.
