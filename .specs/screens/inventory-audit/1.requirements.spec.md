# Auditoría de inventario - Requisitos

## Propósito

Consultar eventos de auditoría de forma comprensible y abrir el recurso afectado
cuando exista una ruta disponible.

## Alcance

- Mostrar acción, tipo de recurso, identificador legible, actor, dispositivo y
  fecha/hora local.
- Permitir buscar y filtrar por intervalo de fechas.
- Expandir un evento para inspeccionar los campos y valores modificados.
- Ofrecer navegación directa al recurso cuando el evento tenga una ruta.

## Criterios verificables

1. Un evento de creación de producto con etiqueta `HJ300-1 · Set demo` presenta
   un título que indica creación de producto y esa etiqueta.
2. El evento muestra actor, dispositivo y fecha/hora en líneas legibles.
3. Un evento con ruta ofrece `Abrir elemento afectado` y navega a esa ruta.
4. Sin ruta, el evento sigue permitiendo expandir los cambios.
