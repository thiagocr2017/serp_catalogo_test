# Auditoría de inventario - Pruebas

## UI

- Dado un evento etiquetado, verificar título localizado y etiqueta del recurso.
- Verificar actor, dispositivo y fecha/hora local.
- Verificar navegación cuando existe `resourcePath`.
- Verificar que un evento sin ruta conserva su expansión y no muestra enlace.
- Uno/dos caracteres dejan el texto sin filtro, tres activan coincidencias y
  borrar debajo del umbral las restaura conservando fechas.
- Una consulta pendiente termina por timeout, muestra el error y al reintentar
  vuelve al estado de carga con una nueva petición.
- La resolución de etiquetas divide 205 IDs de producto y categoría en
  solicitudes de máximo 100, evitando URI excesivamente largas.

## Criterio de listo

Las pruebas de widget cubren los criterios de requisitos sin alterar el
contenido persistido del evento.
