# Lista de promociones - Requisitos

## Proposito

Consultar promociones, reconocer alcance/condicion y abrir su edicion.

## Busqueda

- Buscar por nombre, condiciones o porcentaje desde el tercer caracter.
- Con menos de tres caracteres se muestran todas las promociones.
- Borrar por debajo del umbral restaura resultados inmediatamente.
- La busqueda no cambia el estado ni los datos de las promociones.

## Acciones

- Permitir activar/desactivar y abrir edicion de una promocion.
- Mantener accion visible para crear una promocion.
