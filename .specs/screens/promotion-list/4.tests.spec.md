# Lista de promociones - Pruebas

- Uno o dos caracteres muestran todas las promociones.
- El tercer caracter activa coincidencia por nombre, condiciones o porcentaje.
- Borrar hasta dos caracteres o usar limpiar restaura todas las promociones.
- Un termino de tres o mas caracteres sin coincidencias muestra el estado vacio.
- Filtrar no modifica promociones ni altera sus acciones de estado/edicion.
