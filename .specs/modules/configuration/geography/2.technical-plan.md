# Geografía de Clientes - Plan Técnico

## Arquitectura de Datos

### Migración de Base de Datos
- Archivo: `supabase/migrations/20261004150000_customer_geography_catalogs.sql`
- **Tablas**:
  - `public.countries`: `code text primary key`, `name text not null`, `is_active boolean not null default true`, `created_at timestamptz`.
  - `public.administrative_areas`: `id text primary key`, `country_code text not null references public.countries(code)`, `code text not null`, `name text not null`, `is_active boolean not null default true`, `created_at timestamptz`.
  - `public.cities`: `id text primary key`, `country_code text not null references public.countries(code)`, `province_name text not null`, `name text not null`, `is_active boolean not null default true`, `created_at timestamptz`.
- **Índices de unicidad**:
  - `unique (country_code, lower(btrim(name)))` en `administrative_areas`.
  - `unique (country_code, lower(btrim(province_name)), lower(btrim(name)))` en `cities`.
- **Seguridad**:
  - Row Level Security (RLS) habilitado.
  - Permisos `SELECT` otorgados a `authenticated` y `anon`.
  - Operaciones directas `INSERT`, `UPDATE`, `DELETE` revocadas; escrituras controladas vía RPC `SECURITY DEFINER`.
- **Autoaprendizaje**:
  - `create_customer` y `update_customer` aceptan `p_country_code` y `p_city`.
  - Si `p_city` contiene texto, se verifica existencia contra `cities` y se inserta automáticamente si es nuevo:
    ```sql
    insert into public.cities (id, country_code, province_name, name, is_active)
    values (gen_random_uuid()::text, v_country_code, coalesce(v_province, ''), btrim(p_city), true)
    on conflict do nothing;
    ```
  - Wrappers de compatibilidad con 19 parámetros en PostgreSQL para soportar llamadas históricas de pruebas y clientes existentes.

## Capa de Contratos (Configuration API)

- **DTOs**: `CountryDto`, `AdministrativeAreaDto`, `CityDto` en `lib/modules/configuration/api/configuration_dtos.dart`.
- **Interfaz**:
  ```dart
  Future<List<CountryDto>> getCountries();
  Future<List<AdministrativeAreaDto>> getAdministrativeAreas({String countryCode = 'CR'});
  Future<List<CityDto>> getCities({String countryCode = 'CR', String? provinceName});
  ```
- **Proveedores Riverpod**:
  - `countriesDtoProvider`: `FutureProvider<List<CountryDto>>`
  - `administrativeAreasDtoProvider`: `FutureProvider.family<List<AdministrativeAreaDto>, String>`
  - `citiesDtoProvider`: `FutureProvider.family<List<CityDto>, ({String countryCode, String? provinceName})>`
- **Implementación**: `SupabaseConfigurationApi` en `lib/modules/configuration/data/repositories/supabase_configuration_api.dart`.

## Integración en Sales

- **Entidad y Repositorio**: `Customer` entity y `CustomerRepository` actualizados con `countryCode` (default `'CR'`) y `city`.
- **Formulario (`CustomerFormPage`)**:
  - Dropdown reactivo de País (`customerCountryDropdown`).
  - Si el país es `'CR'`, Dropdown de Provincias con las 7 provincias oficiales de Costa Rica.
  - Si el país no es `'CR'`, TextFormField de Provincia libre.
  - Campo Autocomplete para Ciudad / Distrito (`RawAutocomplete<CityDto>` / `TextEditingValue`), alimentado por `citiesDtoProvider` filtrado por la provincia activa. Helper text indicando que ciudades nuevas se guardarán automáticamente.
- **Perfil (`CustomerProfilePage`)**:
  - Sección de Ubicación con visualización de País, Provincia y Ciudad / Distrito.
