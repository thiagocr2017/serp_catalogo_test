# Product Module Specs

Referencia viva para reglas de negocio del modulo `product`.

El SDD historico vive en `sdd-historical.md`. Al tocar una regla de
productos, extraer la parte relevante a una spec concreta dentro de este
directorio y mantener escenarios verificables.

- `2.packaging-units.spec.md`: factor de conversion de presentaciones a
  unidades base, snapshot comercial y contrato pgTAP requerido antes de
  migrar base de datos/RPC.
