# Inventory Module Specs

Referencia viva para reglas de inventario, documentos, stock, bodegas,
ubicaciones, auditoria e inmutabilidad.

El SDD historico vive en `sdd-historical.md`. Al tocar una regla de
inventario, extraer la parte relevante a una spec concreta dentro de este
directorio.

`returns/1.return-quarantine.spec.md` define el contrato requerido para
cuarentena no vendible, su exclusion del stock disponible y cobertura pgTAP.
